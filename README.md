# AI Resume Assistant

An AI-powered resume assistant that helps users analyze resumes,
match them with job descriptions, and improve their ATS compatibility.

## Project Goals

- Resume parsing
- Job description analysis
- Resume-JD matching
- ATS score analysis
- Resume improvement suggestions
- AI-generated feedback
- Plagiarism/AI-content analysis

## Tech Stack

- Python
- Machine Learning / NLP
- Flask or FastAPI
- Git & GitHub
